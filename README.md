## Быстрый старт

1. Скачайте `Судейская книга.html` (покупатели получают файл после оплаты).
2. Откройте файл двойным кликом — в любом браузере (Chrome, Edge, Firefox).
3. Заполните «⚙ Настройки» (название турнира, город, даты, дни, главный судья).

5. Распределите по татами: вручную или «🎲 Автораспределение».
6. Табелируйте дни, проверьте ведомость — печатайте.
