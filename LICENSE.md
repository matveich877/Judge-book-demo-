# Лицензионное соглашение — «Судейская книга»

Программа «Судейская книга» (одноимённый HTML-файл) является объектом интеллектуальной собственности.

## Условия использования (тарифы «Месяц», «Полгода», «Год»)

1. **Персональная именная лицензия.** Держатель вправе использовать программу для подготовки судейской документации на спортивных соревнованиях, в том числе на своих рабочих и личных компьютерах, а также передавать файл для заполнения членам своей судейской коллегии в рамках одного турнира.
2. **Срок действия** указан в именном файле лицензии (1, 6 или 12 месяцев с даты сборки). По истечении срока программа переходит в режим чтения: данные проекта можно сохранить и выгрузить, редактирование недоступно до продления.
3. **Запрещено:** публиковать исходный файл в открытом доступе (репозитории, файлообменники, чаты), продавать, передавать третьим лицам, извлекать коммерческую выгоду из перепродажи.
4. Оплата производится переводом (СБП) с выдачей чека через сервис «Мой налог» (ИП, налог НПД). Чек является подтверждением лицензии.
5. Программа поставляется «как есть»; автор не несёт ответственности за потерю данных при несоблюдении инструкции по сохранению проекта (кнопка «Сохранить»).
6. Техническая поддержка — через Telegram @matveich877.

*Отдельная категория: бессрочная лицензия выдаётся лично по решению автора (близкие, коллеги, партнёры) и не является публичным предложением.*
