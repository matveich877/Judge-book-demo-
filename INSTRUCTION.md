# 📖 Инструкция: Судейская книга

Полное руководство по работе с программой. Читать 10 минут — потом только пользуетесь.

---

## 1. Установка и запуск

1. Сохраните файл `Судейская книга.html` в удобную папку (например, `Документы/Судейство/`).
2. Откройте двойным кликом — программа запустится в браузере. Работает без интернета.
3. **Важно:** данные автоматически сохраняются в браузере (localStorage). Перед серьёзным турниром нажмите **«💾 Сохранить»** и выберите папку — проект запишется в файл `.json`. Это ваша страховка и способ перенести данные на другой компьютер.

> Совет: заведите папку на турнир. Проект открывается кнопкой «📂 Загрузить».

## 2. Настройки турнира

Кнопка **«⚙ Настройки»** в шапке:

- название соревнований, город, даты;
- **количество дней** — задаёт дневные колонки в табеле и ведомости;
- главный судья и главный секретарь (ФИО + категория) — подставляются в подписи всех документов;
- коэффициент соревнований задаётся на вкладке «Тарифы» (0,8 — региональные, 1,0 — межрегиональные).

## 3. Вкладка «Судьи» — состав

1. **«📋 Вставить списком»** — скопируйте на сайте регистрации список судей (целиком, как есть) и вставьте в окно. Программа сама разложит ФИО, регион, категории, татами, должность. Дубликаты пропускает. Проверьте предпросмотр → «Добавить».
2. Назначьте **должности** из выпадающего списка. Без должности судья — «резерв»: в печать не попадает, но участвует в авторспределении.
3. Заполните категории: **минспорт** — главная, по **кумитэ** и **ката** — для авторспределения по типам площадок.
4. **«⚖️ Жюри»** — отметьте апелляционные жюри (1 или несколько) и супервайзера: списки жюри попадут в «Распределение» и в итоговый список.

## 4. Вкладка «Распределение» → «🎲 Автораспределение»

1. Укажите **число татами** и **тип каждой** (Кумитэ / Ката / Ката+Кумитэ).
2. На каждую площадку вручную выберите **старшего судью** и **замов — от 1 до 3**.
3. **«🎲 Распределить»** — остальные судьи (включая резерв) разойдутся по площадкам случайно, но с балансом:
   - в первую очередь высшие категории минспорта (СМК → СВК → С1К → С2К);
   - баланс категорий минспорта по площадкам (главный критерий);
   - специалисты по ката/кумитэ — на свои площадки; высшая минспорт-категория без профильной дисциплины — допустима;
   - регионы распределяются ровно, включая регионы старших и замов.
4. Проверьте предпросмотр (по каждому татами видно состав и статистику) → **«✔ Применить»**.
5. Доработайте вручную колонкой «Татами» в списке судей. Назначьте должности рефери/секретарям — и все документы обновятся.

## 5. Вкладка «По татами» — табелирование

- Коэффициент дня: **1** — полный день, **0,5** — полдня, **1,2** — переработка, **0** — не работал (пусто = 0). Клик в пустую ячейку сразу ставит 1.
- **Экзамен** (отмечается на вкладке «Судьи») — один день не оплачивается, в ведомости показывается вычет.
- **«🖨 Печать всех татами»** — бланки на каждую площадку для заполнения руками на месте (дни и оценки пустые).
- Оценка 1–5 — уйдёт в итоговый список.

## 6. Вкладка «Тарифы»

Связка **«категория минспорта + должность»** → ставка за день и доп. дни подготовки. Если связки нет — в ведомости горит «⚠ нет тарифа». Коэффициент соревнований (0,8/1,0) умножается на все ставки.

## 7. Вкладка «Зарплатная ведомость»

Расчёт автоматический: ставка × сумма коэффициентов (округление вниз до десятых), доп. дни из тарифа, галочка «+10%», ручная колонка «Разное».

**Панель настроек печати** (галочки над таблицей):
- «скрыть судей с нулевой ЗП»;
- фильтр по категориям — печатайте отдельно ведомости для СВК, С1К и т.д.;
- выбор столбцов печати — уберите ставки/доплаты из чистой распечатки;
- галочки по строкам + кнопки «✔ все / ✘ никто» — итог пересчитывается по отмеченным.

Экспорт: **🖨 печать/PDF**, **⬇ Word**, **⬇ CSV** (для бухгалтерии, разделитель «;» — открывается в Excel).

## 8. Вкладка «Итоговый список»

Печатный список судей для отчётов: ранжирование (ГС → ГСек → замы → остальные по алфавиту), категории в формате для министерства (ССВК, 1К, 2К, 3К, ЮС; должности «Зам. главного судьи», «Арбитр»), оценки, подписи. Внутри программы категории остаются в привычном виде (СВК, С1К) — преобразование только на выводе.

## 9. Вкладка «Экзамен»

1. Заполните настройки: дата, город, место, председатель комиссии, **уровень семинара**.
2. **«📋 Вставить списком»** — поймёт и выгрузку онлайн-теста (ФИО + итоговый процент), и произвольный список.
3. По каждому участнику: дисциплина (Кумитэ/Ката/Тренерский), теория, видеотест (ката), практика, **присвоенная категория**.
4. Документы:
   - **«🖨 Справки сдавшим»** — справка с результатом и категорией (отдельный лист на каждого);
   - **«🖨 Справки слушателям»** — справка о прохождении теорподготовки, уровень семинара подставляется;
   - **«🖨 Протокол»** — шапка, участники, результаты по дисциплинам (у каты — видеотест), подписи.
   Тренерский экзамен попадает в протокол, справки по нему не формируются.

## 10. Вкладка «Отчёт ГС»

Отчёт главного судьи для министерства: наименование, ЕКП, даты/место, организаторы, площадки, волонтёры, участники, травмы, **протесты (добавляются списком с решениями «удовлетворён/отклонён»)**, **сикаку (списком с сроками)**, подписи.

## Частые вопросы

**Q: Закрыл браузер — данные пропали?**
Нет, они в localStorage. Но всегда держите «💾 Сохранить»-файл проекта.

**Q: Как перенести проект на другой компьютер?**
«💾 Сохранить» → скопируйте `.json` → на другом компьютере «📂 Загрузить».

**Q: В ведомости «нет тарифа»?**
Добавьте связку категория+должность на вкладке «Тарифы» — ведомость пересчитается сама.

**Q: Судья в резерве — где он?**
В авторспределении и в табеле. В печатных документах появится, как только назначите должность.

**Q: Можно двоим работать одновременно?**
Проект — один файл JSON. Работайте по очереди или на одном компьютере, пересылая файл между собой.
