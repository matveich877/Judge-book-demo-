🥋 Судейская книга

Вставка судей списком

Скопируйте список с сайта регистрации и вставьте сюда как есть. Программа понимает родной формат сайта (№, ФИО, регион, категории, татами, должность) и раскладывает всё по полям автоматически. Также понимает обычный текст с пробелами. Дубликаты по ФИО пропускаются. Ниже появится предпросмотр — проверьте, что всё распозналось.

Вставка результатов экзамена списком

Вставьте список участников как есть — из Excel (выгрузка теста: №, ФИО, даты, ход, результат), с сайта регистрации или обычный текст (ФИО, регион, категория, дисциплина). Программа сама найдёт ФИО, регион, категорию, дисциплину (кумитэ/ката/тренерский) и процент теории. Дубликаты пропускаются.

Автораспределение судей по татами

1) Задайте количество татами, тип каждой площадки (кумитэ / ката / ката+кумитэ) и вручную назначьте старшего судью с замом. 2) Нажмите «Распределить» — остальные судьи разойдутся по площадкам случайно, но с балансом: равномерно по числу, категориям и регионам. 3) Проверьте предпросмотр и примените. После этого раскладку можно подправить вручную (колонка «Татами» в списке судей). Распределяются все, включая резерв — должности назначаются после. На печать по-прежнему попадают только судьи с должностью.

Аппеляционное жюри

Отметьте судей из рабочего состава. Список жюри выводится в итоговом списке судей.
